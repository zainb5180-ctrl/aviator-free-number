# Aviator Ads-Coin Simulator

**Aviator Ads-Coin Simulator** is an educational and entertainment web tool that allows users to earn virtual coins by watching ads and run a simulated test once a minimum coin balance is reached.

---

## Features

- **Watch Ads → Earn Coins** (5 Coins per Ad)  
- **Minimum 30 Coins required** to run the Test  
- **Wallet balance tracking** for users  
- **Ad placeholders ready** for AdSense or custom images  
- Fully functional simulation in browser (no backend required)

---

## How It Works

1. Open the website (`index.html`) in your browser.  
2. Click on any Ad placeholder → Earn 5 Coins per click.  
3. When your coin balance reaches **30 Coins**, the "Run Test" button becomes active.  
4. Click **Run Test** → 30 Coins will be consumed, and the simulation starts.  
5. Repeat Ads watching to earn more Coins for additional tests.

---

This tool is for **educational and entertainment purposes only**.  
No real money or financial transactions are involved.  
Coins and Ads are purely for simulation purposes.
